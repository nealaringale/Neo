# Neo

Neo is a personal AI assistant for the laptop.

V1 focuses on a clean Python foundation:
- deterministic command routing
- safe laptop actions
- local memory
- extensible tool modules
- logging and configuration

Run with:

python main.py

Example commands:
help
status
open vscode
open calculator
open browser
search python decorators
remember editor = VS Code
recall editor
exit

Future versions will add an LLM brain, voice, screen understanding, browser automation, coding workflows, GitHub integration, and richer memory.
